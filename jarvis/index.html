답은 하나로.

어떻게 토론하나요?

한 AI의 답만 믿지 않고, 세 AI가 서로를 검토하게 만듭니다.

STEP 1

각자 첫 답변

ABC

ChatGPT(A) · Claude(B) · Gemini(C)가 서로의 답을 보지 않고 독립적으로 답합니다.

STEP 2

서로 보고 다시 답변

A ← B·CB ← A·CC ← A·B

각 AI가 다른 두 AI의 실제 답을 읽고, 받아들일 점은 받아들이고 틀린 점은 반박하며 다시 답합니다.

STEP 3

최종 검수 · 하나의 답

🏁 검수자

검수자가 세 답을 검토해 최종 답변을 쓰고, 합의된 점 · 의견이 갈린 점 · 주의점을 함께 정리합니다.

특징

초보자도 더블클릭으로 쓸 수 있게 만들었습니다.

🔎

웹 검색으로 사실 확인

각 AI가 직접 검색해 사실·수치를 확인하고 출처 링크를 답니다. 다른 AI가 단 출처도 서로 검증해요.

✍️

실시간으로 써 내려가는 답변

세 AI가 답을 쓰는 모습이 글자 단위로 바로 보입니다. 지금 진행 중인 단계가 항상 맨 위에 떠요.

🏁

검수자는 내가 선택

세 답변을 검토해 최종 답을 쓸 AI를 OpenAI · Claude · Gemini 중에서 직접 고릅니다. 답변은 익명으로 전달돼요.

📎

PDF · 문서 첨부

논문이나 보고서 PDF를 올리고 "이거 검증해 줘"라고 물어볼 수 있습니다. 글자만 꺼내 보냅니다.

↪️

이어서 질문하기

토론 결과에 대해 바로 후속 질문을 할 수 있습니다. 이전 결론을 참고해 다시 토론해요.

💸

비용 표시 · 상한 설정

공식 요금표로 예상 비용을 미리 보여 주고, 정한 금액(기본 $1)에 닿으면 자동으로 멈춥니다.

🤖

질문 수준에 맞게 자동 선택

쉬운 질문엔 저렴한 모델, 어려운 질문엔 가장 똑똑한 모델을 자동으로 고릅니다. 직접 고를 수도 있어요.

🛟

한 AI가 멈춰도 계속

크레딧이 떨어지거나 오류가 난 AI는 자동으로 빼고, 남은 AI끼리 끝까지 토론합니다.

🔒

내 컴퓨터에서만 실행

회원가입이 없고, 질문은 내가 고른 AI 회사로만 전송됩니다. 키는 내 컴퓨터에만 저장돼요.

⏹️

언제든 중단

답변 생성 중에 중단 버튼을 누르면 바로 멈추고, 그때까지의 내용은 저장됩니다.

📚

기록 자동 저장

모든 토론이 자동 저장되고, Markdown 파일로 내려받거나 이전 기록을 다시 열어볼 수 있습니다.

설치 설명서

처음 한 번만 따라 하면, 다음부터는 더블클릭 한 번으로 실행됩니다. 사용하는 컴퓨터를 고르세요.

  1. 1

    Python 준비

    Mac에는 보통 Python이 들어 있습니다. 없으면 처음 실행할 때 "개발자 도구를 설치하겠습니까?" 창이 뜨는데, 설치를 누르고 끝난 뒤 다시 실행하면 됩니다.

    더 안정적으로 쓰고 싶다면 python.org에서 최신 Python(3.12 이상)을 설치하세요.

  2. 2

    다운로드하고 압축 풀기

    위의 다운로드 버튼을 누르면 보통 다운로드 폴더에 저장됩니다. zip 파일을 더블클릭하면 라비스 폴더가 생깁니다. 원하는 곳(예: 데스크탑)으로 옮겨도 됩니다.

  3. 3

    실행하기.command 열기

    인터넷에서 받은 파일이라 처음엔 Mac이 막을 수 있습니다. 아래 순서대로 한 번만 허용해 주세요.

    1. 실행하기.command를 더블클릭 → "확인할 수 없습니다" 창이 뜨면 완료(또는 취소)
    2. 시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 "그래도 열기" 클릭 → 다시 열기

    이것도 어렵다면 터미널 앱을 열고 아래 명령을 붙여 넣어도 됩니다 (라비스 폴더가 다운로드 폴더에 있을 때):

    cd ~/Downloads/라비스 && zsh 실행하기.command

    처음엔 필요한 프로그램을 설치하느라 1~3분 걸립니다. 끝나면 브라우저에 http://localhost:8501이 자동으로 열립니다.

  4. 4

    API 키 발급받기

    아래 API 키 발급 방법을 보고 쓰고 싶은 회사의 키를 만드세요. 하나만 있어도 실행되고, 둘 이상이면 토론이 됩니다.

  5. 5

    키 넣고 연결 테스트

    프로그램 왼쪽 메뉴 ⚙️ 설정 · API 키 → 키 붙여넣기 → 🔒 키 저장 → 🔌 연결 테스트. "✅ 연결 성공"이 나오면 끝!

  6. 6

    다음부터는

    실행하기.command 더블클릭 한 번이면 됩니다. 다 쓴 뒤에는 터미널 창을 닫으면 프로그램이 꺼집니다.

API 키 발급 방법

공통 순서: 가입 → 결제(크레딧) 등록 → 키 만들기 → 복사. 키는 만들 때 한 번만 보이니 바로 복사하세요.

A OpenAI (ChatGPT)
  1. platform.openai.com 접속 → 로그인 (ChatGPT 계정 그대로 가능)
  2. Settings → Billing에서 결제 수단 등록 후 크레딧 충전
  3. API keys → Create new secret key → 이름 "라비스" → 생성된 sk-... 키 복사
B Anthropic (Claude)
  1. console.anthropic.com 접속 → 가입/로그인 (claude.ai 구독과는 별개)
  2. Billing에서 카드 등록 → Buy credits로 충전 (처음엔 자동 충전은 꺼 두는 것을 추천)
  3. API Keys → Create Key → 이름 "라비스" → 생성된 sk-ant-... 키 복사
C Google Gemini
  1. aistudio.google.com/apikey 접속 → Google 계정 로그인
  2. Create API key → 생성된 AIza... 키 복사
  3. "free tier is not available" 오류가 나면 결제 설정에서 유료 등급으로 전환

🔑 API 키는 비밀번호와 같습니다

키는 프로그램의 설정 화면에만 넣으세요. 채팅·DM·댓글에 붙여 넣거나, 키가 저장된 .env.local 파일을 다른 사람에게 보내면 남이 내 돈으로 AI를 쓸 수 있습니다. 유출이 의심되면 해당 콘솔에서 키를 바로 삭제하세요.

    쉬움GPT-6 LunaHaiku 5.53.8 Flash
    보통GPT-6.1 SolSonnet 5.53.8 Flash

    질문을 입력하고 ▶️ 토론 시작. 필요하면 📎 파일 첨부로 PDF·TXT·MD를 함께 보낼 수 있어요. 각 AI가 답을 쓰는 모습이 실시간으로 보이고, 언제든 ⏹️ 중단할 수 있습니다.

  3. ③

    결과 확인

    맨 위에 🏁 최종 답변, 아래에 각 AI의 단계별 답변이 나옵니다. 각 답변 아래 🔗 참고한 출처를 열어 근거를 확인할 수 있어요. 결과는 자동 저장되며 💾 Markdown 파일로 저장, ↪️ 이 결과에 이어서 질문하기도 가능합니다.

자주 묻는 질문 · 문제 해결

대부분의 문제는 화면에 한국어로 원인과 해결 방법이 표시됩니다.

실행했는데 브라우저가 안 열려요

브라우저 주소창에 http://localhost:8501을 직접 입력해 보세요. 처음 실행은 설치 때문에 1~3분 걸릴 수 있습니다. 터미널(검은 창)에 오류 문구가 있다면 그 내용을 확인하세요.

"API 키가 올바르지 않습니다"라고 나와요

키를 끝까지 다 복사했는지 확인하고, 설정 화면에서 다시 저장하세요. 콘솔에서 키를 새로 만들어 넣어도 됩니다.

"크레딧(잔액) 또는 결제 설정이 부족합니다"라고 나와요

해당 회사 콘솔의 Billing에서 결제 수단 등록과 충전이 필요합니다. 웹 구독(Plus/Pro)만으로는 API를 쓸 수 없습니다. 그동안은 그 AI를 빼고 나머지 AI끼리 토론합니다.

"모델을 찾을 수 없습니다"라고 나와요

설정 화면의 🔌 연결 테스트를 누르면 내 계정에서 쓸 수 있는 모델 목록이 나옵니다. 목록에서 골라 이 모델 사용을 누르세요. 자동 선택 모드에서는 쓸 수 없는 모델이면 직접 고른 모델로 자동 대체됩니다.

비용은 얼마나 나오나요?

모델, 답변 길이, 웹 검색 여부에 따라 다릅니다. 기본 설정(중간 모델 · 보통 길이 · 웹 검색 켜짐)이면 토론 1회에 대략 $0.1~0.5 정도이고, 시작 전에 예상 비용이 표시됩니다. 웹 검색은 1,000회당 $10~14가 추가됩니다.

토론 1회 비용 상한(기본 $1)에 닿으면 남은 단계를 자동으로 멈추며, 설정에서 바꿀 수 있어요. 비싼 모델(Astra·Opus·Fable·Argon)과 '길게' 설정은 비용이 커집니다. 각 회사 콘솔에서 월 사용 한도도 설정해 두면 더 안심할 수 있어요. 표시되는 비용은 추정치이며 실제 청구 금액은 각 회사 콘솔에서 확인하세요.

내 질문은 어디로 전송되나요?

내가 켜 둔 AI 회사(OpenAI · Anthropic · Google)의 API로만 전송됩니다. 제작자나 다른 분석 서비스로는 아무것도 전송되지 않으며, 프로그램은 내 컴퓨터(127.0.0.1)에서만 열립니다. 각 회사의 데이터 처리 방식은 해당 회사의 API 약관을 따릅니다.

새 버전은 어떻게 받나요?

이 페이지에서 새 zip을 받아 압축을 푼 뒤, 기존 폴더의 .env.local(키)과 토론기록 폴더를 새 폴더로 옮기면 됩니다.

Mac에서는 이름이 점(.)으로 시작하는 .env.local이 Finder에 숨겨져 있습니다. 라비스 폴더를 연 상태에서 Command + Shift + .(마침표)를 누르면 보입니다. 옮기기 어렵다면 새 폴더에서 키를 다시 저장해도 됩니다.
